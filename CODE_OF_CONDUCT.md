# Code of Conduct

## Our Standard

Sèo Trum is an open-source project for practical SME social operations. We welcome contributors who keep discussion technical, respectful, and useful.

Participants are expected to:

- Be respectful when reviewing ideas, code, documentation, and bug reports.
- Assume good intent, but be concrete when pointing out risks or mistakes.
- Keep issues and pull requests focused on the project.
- Avoid sharing private customer data, credentials, screenshots with secrets, or personal information.

Unacceptable behavior includes harassment, insults, spam, doxxing, publishing secrets, or repeatedly derailing technical discussion.

## Enforcement

Maintainers may edit or remove comments, close issues, reject pull requests, or block participants who violate this code of conduct.

For sensitive concerns, use the private reporting path described in [SECURITY.md](SECURITY.md).
