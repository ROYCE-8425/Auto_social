# Dataset ảnh Fanpage

Folder theo chủ đề / thương hiệu. Trang Brand kit trên dashboard đọc thư mục này.

- `chung` - logo, banner chung của hệ thống
- `game-bsn` - kho ảnh screenshot, poster bản quyền Steam / PC Game (Game Giá Rẻ BSN)
- `_mau` - hướng dẫn bố cục bài viết
- `_xuat` - nơi xuất ảnh bìa cover AI và album ảnh đã chuẩn hóa
- `_xuat-tiktok` - video và nội dung xuất bản cho kênh TikTok

Đăng bài: chọn đúng folder tương ứng với thương hiệu Fanpage.
