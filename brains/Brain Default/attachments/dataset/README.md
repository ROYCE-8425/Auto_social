# Dataset ảnh Fanpage

Folder theo chủ đề. Trang Brand kit trên dashboard đọc thư mục này.

- `chung` - logo, banner hệ thống
- `tin-hoc` - văn phòng, MOS, lớp máy tính
- `tieng-han` - khoá tiếng Hàn
- `co-khi` - AutoCAD, SolidWorks, CNC
- `do-hoa` - Photoshop, AI đồ họa
- `ke-toan` - kế toán thực hành
- `marketing` - ads, SEO
- `ai` - AI văn phòng
- `tre-em` - tin học / lập trình trẻ em

Đăng bài: chọn đúng folder + đúng Fanpage. Không lấy logo trong `chung` làm ảnh chủ đề.
