Khối lượng bài mỗi tuần = số page x số bài mỗi page mỗi tuần. Với giả định 60 page và 2 bài mỗi page mỗi tuần, khối lượng là 120 bài mỗi tuần [[conversations/2026-09-08]].

Tổng token mỗi tuần = số bài mỗi tuần x token trung bình mỗi bài. Với giả định 120 bài mỗi tuần và 800k token mỗi bài, tổng token là 96.000.000 token mỗi tuần [[conversations/2026-09-08]].

Tổng token 4 tuần = tổng token mỗi tuần x 4. Với mức 96.000.000 token mỗi tuần, tổng 4 tuần là 384.000.000 token [[conversations/2026-09-08]].

Tổng token 1 năm = số bài mỗi tuần x 52 x token trung bình mỗi bài. Với 120 bài mỗi tuần và 800k token mỗi bài, tổng năm là 4.992.000.000 token [[conversations/2026-09-08]].

Khi đánh giá scale, nên tính ít nhất 2 kịch bản: không giảm giá cache và có giảm giá cache, vì workflow gần nhất có tỷ lệ cache read rất cao [[conversations/2026-09-08]].
