# Support

Sèo Trum / Auto_social uses GitHub as the public support and coordination hub.

## Ask a question

Open a GitHub Issue and choose the closest template. Include:

- what you are trying to do,
- the route or command involved,
- your operating system,
- the relevant log excerpt,
- whether you are running Docker, local Python, or the Ops frontend dev server.

Do not paste secrets, access tokens, API keys, real customer conversations, phone numbers, or private page tokens.

## Report a bug

Use the bug report issue template. A good report includes:

- expected behavior,
- actual behavior,
- reproduction steps,
- command output or screenshot with sensitive data hidden,
- the commit SHA or release version.

## Request a feature

Use the feature request template. Please explain the workflow and user role first. The project favors real social-commerce operations workflows over duplicate dashboard cards or presentation-only features.

## Security issues

Do not open a public issue for vulnerabilities. Follow [SECURITY.md](SECURITY.md).

## Releases and announcements

Public release notes are tracked in [CHANGELOG.md](CHANGELOG.md), [VERSION](VERSION), and the release process in [docs/RELEASE_PROCESS.md](docs/RELEASE_PROCESS.md).
